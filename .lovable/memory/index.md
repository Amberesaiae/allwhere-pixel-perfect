# Project Memory

## Core
BlueKiosk: Ghana marketplace with allwhere cream/yellow/dark design palette. IBM Plex Sans font.
Listing-centric classifieds model (Jiji/Tonaton style). No Shopify, no cart, no e-commerce checkout.
Token classes: bk-cream, bk-yellow, bk-dark, bk-beige, bk-muted (same as old aw- tokens).
Discover page uses TanStack search params with zod-adapter for category/tab URL state.
